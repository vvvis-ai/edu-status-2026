## 저장 방식 전환

R2 활성화가 계정의 구독 등록 절차를 요구하여, 사용자가 승인한 Workers KV 저장 방식으로 전환했습니다. R2 버킷 생성·결제정보 입력·구독 등록·약관 동의는 수행하지 않았으며 현재 Worker 구성에 R2는 없습니다.

Workers Free의 KV 저장 제공량은 1GB, 쓰기는 하루 1,000키입니다. 파일당 한도는 앱에서 15MiB로 유지합니다. 재제출한 이전 원본도 보존하므로 전체 이력이 용량에 누적됩니다. 계정 내 다른 KV 사용량도 함께 확인해야 합니다. 파일 반영은 지역에 따라 60초 이상 지연될 수 있으며, 새 파일 조회가 늦어지면 잠시 후 재시도하도록 안내합니다. 자세한 제공량과 제약은 [운영안내](운영안내.md)의 KV 항목에 기록했습니다.

## 운영·후속 배포

앱 수정 후 `npm test`, `npm run check`, `npm run deploy:dry-run`을 확인하고 `npm run deploy`로 배포합니다. 서버 secret은 비공개 `.dev.vars`에서 코드와 함께 설정합니다. 기존 데이터에 초기 이관 SQL을 다시 적용하거나 운영 DB를 초기화하지 않습니다.

`main`의 Pages workflow는 연결 HTML만 게시합니다. Worker 코드는 `npm run deploy`로 별도 배포합니다. 주소 변경 시 검증한 origin을 `deployment.json`에 기록하고 기존 두 진입 경로의 이동까지 확인합니다.

원격 기존 운영 API 쓰기·기존 데이터 삭제는 수행하지 않습니다. 수료증 원본·비공개 초기 SQL·secret은 공개 저장소에 포함하지 않습니다. 파일은 선택 사용자 또는 관리자 세션을 확인하는 Worker API를 통해서만 제공합니다.
